##### Databricks Unity Catalog

StarRocks 3.5 supports Databricks Unity Catalog (UC) as a Delta Lake metastore. The FE uses the UC REST API to list metadata, load Delta tables, and optionally vend short-lived table credentials for storage reads.

Configure `MetastoreParams`:

```SQL
"hive.metastore.type" = "unity",
"unity.catalog.host" = "https://<workspace-host>",
"unity.catalog.token" = "<databricks-pat>",
"unity.catalog.name" = "<uc-catalog-name>",
"unity.catalog.vended-credentials-enabled" = "true"
```

Parameters:

| Parameter | Required | Description |
| --------- | -------- | ----------- |
| hive.metastore.type | Yes | Must be `unity`. |
| unity.catalog.host | Yes | Databricks workspace URL. Trailing slashes are stripped. |
| unity.catalog.auth.type | No | `pat` (default) or `oauth-m2m`. The credential sets are mutually exclusive. |
| unity.catalog.token | Conditional | PAT or service-principal token with table access. Required for `pat`; not allowed for `oauth-m2m`. |
| unity.catalog.client-id | Conditional | Service-principal OAuth client ID. Required for `oauth-m2m`. |
| unity.catalog.client-secret | Conditional | Service-principal OAuth client secret. Required for `oauth-m2m`. |
| unity.catalog.name | Yes | UC catalog exposed as the StarRocks external catalog. |
| unity.catalog.vended-credentials-enabled | No | Default `true`. Uses UC `temporary-table-credentials`; failures fail fast in FE. Set `false` to use `StorageCredentialParams`. |
| unity.catalog.spoof-user-agent | No | Default `false`. Set `true` to send a Spark-like user agent when StarRocks is not whitelisted. Requires catalog re-creation. |
| unity.catalog.request-timeout-ms | No | Default `30000`. UC request timeout in milliseconds. |
| unity.catalog.max-retries | No | Default `3`. UC delta/v1 retries after the initial request. |
| unity.catalog.cache.enabled | No | Default `true`. Caches UC metadata and Unity catalog snapshots. Credential caching is separate. |
| unity.catalog.delta-cache.enabled | No | Default `true`. Controls the shared FE Delta JSON/checkpoint cache. |
| unity.catalog.cache.ttl-sec | No | Default `60`. UC metadata TTL; also bounds vended snapshot TTL. `0` bypasses UC metadata and snapshot caches. |
| unity.catalog.cache.credentials.ttl-sec | No | Default `1200`. TTL for cached vended credentials. `0` disables credential retention. |
| unity.catalog.cache.credentials.safety-margin-sec | No | Default `1200`. Re-vend before the earliest credential `expirationTime`; credentials without expiration are not cached. |
| unity.catalog.aws.region | Conditional | Optional AWS region override. Required if AWS vended credentials are enabled and `metastores.summary` cannot return a region. |

With vended credentials enabled, AWS S3 and Azure ADLS Gen2 can usually omit `StorageCredentialParams`; GCS uses catalog-level credentials.

**Example: PAT auth**

```SQL
CREATE EXTERNAL CATALOG unity_pat
PROPERTIES (
    "type" = "deltalake",
    "hive.metastore.type" = "unity",
    "unity.catalog.host" = "https://<workspace-host>",
    "unity.catalog.token" = "<databricks-pat>",
    "unity.catalog.name" = "main",
    "unity.catalog.vended-credentials-enabled" = "true"
);
```

**Example: OAuth M2M auth**

```SQL
CREATE EXTERNAL CATALOG unity_oauth
PROPERTIES (
    "type" = "deltalake",
    "hive.metastore.type" = "unity",
    "unity.catalog.host" = "https://<workspace-host>",
    "unity.catalog.auth.type" = "oauth-m2m",
    "unity.catalog.client-id" = "<service-principal-application-id>",
    "unity.catalog.client-secret" = "<service-principal-oauth-secret>",
    "unity.catalog.name" = "main",
    "unity.catalog.vended-credentials-enabled" = "true"
);
```

###### Caching

- UC metadata caches use `unity.catalog.cache.enabled` and `unity.catalog.cache.ttl-sec`.
- Vended credentials use `unity.catalog.cache.credentials.ttl-sec` and are reused only while `expirationTime - safety_margin > now`.
- The shared Delta JSON/checkpoint cache is controlled by `unity.catalog.delta-cache.enabled`.

`unity.catalog.cache.enabled = false` or `unity.catalog.cache.ttl-sec = 0` bypasses UC metadata and Unity catalog snapshot caches. It does not disable credential caching.

###### AWS region

For AWS vended credentials, StarRocks infers the region from one `metastores.summary` call per catalog unless `unity.catalog.aws.region` is set. Missing AWS region fails vending. Azure and GCP do not use this setting.

###### Catalog snapshot cache

Unity catalog snapshots use `metastore_cache_ttl_sec`. With vended credentials enabled, StarRocks clamps the snapshot TTL to the smallest of `unity.catalog.cache.ttl-sec`, `unity.catalog.cache.credentials.ttl-sec`, and `unity.catalog.cache.credentials.safety-margin-sec`.

For vended Unity catalogs, snapshot refresh-after-write (`metastore_cache_refresh_interval_sec`) is disabled; expired snapshots reload on next access. Non-vended Unity catalogs still honor `metastore_cache_refresh_interval_sec`. To bypass the snapshot cache for a session or query, set `enable_unity_table_snapshot_cache = false`.

###### Shared Delta metadata-file cache

The shared FE JSON/checkpoint cache is configured in `$STARROCKS_HOME/conf/unity-cache.properties` and read at FE start. Per-catalog DDL does not configure these values.

| Property | Default | Description |
|---|---|---|
| `unity.delta.json.meta.cache.ttl-sec` | `86400` | Parsed Delta JSON log TTL. |
| `unity.delta.json.meta.cache.memory-usage-ratio` | `0.1` | FE heap ratio for JSON logs. |
| `unity.delta.checkpoint.meta.cache.ttl-sec` | `86400` | Parsed Delta checkpoint TTL. |
| `unity.delta.checkpoint.meta.cache.memory-usage-ratio` | `0.1` | FE heap ratio for checkpoints. |

Malformed values fall back per key.
